# A4 proposal: validate each undirected coarse move once

Preregistered before implementation. A2 proved legalNavMove symmetry for unit8px moves on76maps, while retaining the full original validator. A3 inline did not speed that validator. The validator currently repeats the same geometry predicate in both directions. Reuse the A2 symmetry proof and canonical direction ownership to check geometry once per undirected pair while retaining every directed bit's bounds and reverse-bit checks. This changes execution cost, not the set of accepted graphs.

Required proof: every set bit must lead to an in-bounds endpoint; every bit must have its reverse. Those conditions partition all set bits into pairs; checking legalNavMove for exactly one canonical orientation proves both. Bounds must be checked BEFORE reverse indexing, including negative-direction bits at borders. Corrupt a good index by adding illegal symmetric pairs, removing one reverse, and adding each possible out-of-board direction; the public validator must reject each. Use an independent full-eight-direction reference validator over the coarse bit array and compare accept/reject across systematic mutations. Do not skip validation under a build flag or merely trust the constructor.

Target map48 margin rather than a single passing sample. Keep all other validator passes unchanged.

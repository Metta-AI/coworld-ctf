# P1 proposal: separable 3x3 hot-bit dilation

After D1 code review, independently review this next hypothesis, documents only. `rebuildPackedWeights` currently converts all float cells, then for every raw-positive cell ORs the hot bit into up to9 neighbors, doing division/modulo and bounds checks. This is exactly a 3x3 square binary dilation of raw(value>0), combined with unchanged packed Q8 low bits.

Established semantics: SciPy binary_dilation with an all-ones3x3 structure (https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.binary_dilation.html), OpenCV dilation (https://docs.opencv.org/4.8.0/db/df6/tutorial_erosion_dilatation.html). These libraries support the general operation; adding Python/SciPy or OpenCV to the Nim native/wasm simulation for this fixed3x3 boolean operation is heavier than the local loop and adds a cross-toolchain dependency. Proposed local streaming separable form needs no array allocation.

For each output row y, hoist row offsets above/current/below (clamp duplicate edge rows; OR idempotence makes duplication exact). columnHot(x) is rawpositive in any of those3 rows. Carry leftHot=false and centerHot=columnHot(0); each x computes rightHot=columnHot(x+1) if in range, elsefalse; emit unchanged packedDangerQ8(currentvalue) with highbit iff leftHot or centerHot or rightHot; shiftleft=center, center=right. One packedwrite per cell; no division/modulo; at most3 positive comparisons per inputcolumn. Preserve validation of rasterlength and packed15bit overflow. Low Q8 rounds tozero for tinypositive values but highbit must STILL use rawpositive. NaN is not a valid generated danger value; do not introduce a new NaN contract casually.

Please verify semantics at all borders/corners,1-wide/1-high, zero/tinypositive/rangeboundary inputs, no new memory, and whether scalar shortcircuit/data sparsity could make this lose against currentloop. Suggest smallest independent differential test with literal expected masks, not just a duplicated implementation. Write P1_REVIEW.md. Do not implement yet; D1 must finish its own checkpoint.

# C11 coordinate-domain finding

Root read body_map.cellOf: it clamps point div8 to the map grid. rebuildDanger accepts public DangerInput candidates without a coordinate-range check. Therefore a close-floor optimization must not silently assume source.x - origin.x*8 and source.y - origin.y*8 are in0..7 unless the caller contract is proven. For an off-map source the old loop centers its search box on the clamped origin but computes distance from the original point. Please include negative and beyond-map source coordinates in the clipped predicate/interval proof or explicitly leave this as a blocking contract question before implementation. The interval formula can use actual source minus clamped origin and still compare exactly; a fixed64phase lookup cannot directly cover that domain. No new defensive source validation is requested.

# JOURNEY MAP — the beginner's journey on softmax, walked

**Era:** 2026-09-09; live ladder paintbot-v0.7.374 (GameVersion 61 / GLORYVERSION 16); coworld-ctf main 41230869. **Persona:** a curious developer who has never heard of Paintbot.

This is a MAP: what is, not what should be. No recommendations, no fixes proposed. Numbers below are click counts and command counts only.

## 1. Era + method

Five fresh, signed-out, script-driven browsers, one per entry point, each in its own profile: HOME (softmax.com), the door (/paintbot direct), three cold entries (a shared replay link, a forum post, a search result), plus docs.softmax.com cold and the GitHub README cold (the last five run by one walker, `jm-links`, as five separate cold profiles). No sign-in was attempted anywhere; no submission was made. Post-submission hallways (standings after submit, the score-bug strip, the endcard, iteration) are mined from two Walk-1 stranger transcripts (`sonnet-a`, `sonnet-b`) plus a live standings re-check today — Walk 1 itself is void as a measurement (its prompt named the milestones it was scoring), but the surfaces it touched and the defects it hit are real, cited by transcript line offset. Prior-art claims are read verbatim from landed docs, open PRs, owner rulings, and live curls, not re-derived. Live-status curls in this map were run 2026-09-09 and cited where a status disagrees with a walker's same-day observation.

**Not covered:** a real submission carried out by a beginner walker (all five entry-walks stopped before sign-in/submit by hard rule); the endcard as observed live by any entry-walker (one cold replay link reached an endcard-equivalent screen by manually seeking, not by watching a round end); the Observatory league dashboard's actual content (every anonymous route into it hits a sign-in wall).

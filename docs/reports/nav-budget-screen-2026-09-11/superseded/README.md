# Rejected setup — historical evidence only

Do not use this harness or its protocol to decide a production budget.
Independent review rejected both before native timings ran. The 4/5 ms gate
was incorrectly borrowed from the archived routing rewrite; simplified motion,
fixed aim and zero cooldown also distorted navigation behavior. The harness
was smoke-tested locally, and native binaries were built, but no native timing
sweep from this setup is used. The original import paths assume the file lived
under `tools/`; it is retained here as evidence, not as a runnable tool.

Use the parent directory's real-server protocol and scripts instead.
